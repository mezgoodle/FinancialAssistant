# Financial Assistant AI (Google ADK + Supabase)

Персональний фінансовий асистент на базі **Google Agent Development Kit (ADK) / Google GenAI SDK** та **Supabase (PostgreSQL)**, розроблений на Python з використанням менеджера пакетів **`uv`**.

Асистент приймає банківські виписки та файли додатків обліку фінансів (CSV, XLSX), автоматично аналізує доходи й витрати, зберігає історію з дедуплікацією та відповідає на запитання щодо витрат за будь-які періоди (цього місяця, минулого місяця, рік тому).

---

## 🌟 Основні можливості

- 📊 **Універсальний парсер файлів (CSV / XLSX)**:
  - Підтримка експорту **Money Manager**
  - Підтримка виписок **Monobank**
  - Підтримка виписок **ПриватБанк**
  - Автоматичне визначення розділювачів та колонок (Fuzzy matching)
- 🔒 **SHA-256 Дедуплікація**: Безпечний повторний імпорт файлів без дублювання записів.
- 🗄️ **Supabase PostgreSQL**: Надійне збереження структурованих транзакцій та аналітичних індексів (з можливістю локальної роботи).
- 🤖 **Google ADK Agent & Function Calling**:
  - `ingest_financial_file`: Імпорт та збереження нових файлів
  - `query_transactions`: Пошук за категоріями, діапазонами сум та ключовими словами
  - `get_period_summary`: Розрахунок витрат, доходів та категорій за місяць/рік
  - `compare_periods`: Порівняння періодів (місяць-до-місяця MoM, рік-до-року YoY)
- 💻 **Інтерактивний Web UI**: Сучасний веб-інтерфейс із підтримкою Markdown, завантаженням файлів та швидкими підказками.

## 🚀 Швидкий старт

### 1. Встановлення залежностей через `uv`

```bash
# Синхронізація віртуального оточення
uv sync
```

### 2. Налаштування змінних оточення

Скопіюйте приклад файлу конфігурації `.env.example` у `.env`:

```bash
cp .env.example .env
```

Заповніть змінні у `.env`:

```env
# Ключ Google Gemini API (https://aistudio.google.com/)
GEMINI_API_KEY=your_gemini_api_key_here

# Налаштування Supabase (опціонально, є локальний фолбек)
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your_supabase_anon_key

# Порт веб-інтерфейсу
PORT=8000
```

### 3. Запуск веб-інтерфейсу та асистента

```bash
uv run python main.py
```

Після запуску відкрийте у браузері: **`http://localhost:8000`**

│   │   ├── repository.py            # Репозиторій транзакцій та агрегацій

│   ├── test_parser.py               # Тести парсерів та дедуплікації
│   ├── test_repository.py           # Тести методів репозиторію та аналітики
│   ├── test_tools.py                # Тести викликів аналітичних інструментів

├── pyproject.toml                   # Залежності проєкту (uv)

## 💬 Приклади запитів до асистента

1. **Імпорт файлу**:
   * *Завантажте файл через кнопку "Завантажити CSV/XLSX" або напишіть:*
   * `Проаналізуй файл data/samples/sample_money_manager_2026.csv`

2. **Аналіз витрат**:
   * *«Скільки я витратив на продукти цього місяця?»*
   * *«Які мої найбільші категорії витрат за останній місяць?»*

3. **Історичне порівняння**:
   * *«Порівняй мої витрати за серпень 2026 року із серпнем 2025 року.»*
   * *«На скільки більше чи менше я витратив цього місяця порівняно з минулим?»*
